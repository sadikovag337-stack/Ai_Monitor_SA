# AI MONITOR v3.0 — Центр видеонаблюдения

## Что нового
1. **Хакерский терминальный загрузчик** (`START_AI_MONITOR.bat` и `run.py`) с матричной графикой, прогресс-баром и выводом локального + сетевого IP.
2. **Поддержка веб-камеры ноутбука:** можно тестировать систему без IP-камер. В интерфейсе появилась кнопка **«📷 Подключить камеру ноутбука»** (или вручную указать адрес `local://0` для встроенной камеры и `local://1` для внешней USB-камеры).
3. **Поиск IP-камер в локальной сети:** нажмите **«🔎 Найти камеры в локальной сети»**. Обнаружение использует ONVIF WS-Discovery; ONVIF должен быть включен на камере. Найденные камеры автоматически добавляются в список без дублирования. Для подключения нажмите **«Настроить RTSP»** у камеры и укажите корректный RTSP-путь и учетные данные, если они требуются. Поиск не сканирует интернет.

## Запуск
1. Распакуйте архив в любую папку.
2. Запустите **`START_AI_MONITOR.bat`** (двойным кликом или в терминале VS Code `.\START_AI_MONITOR.bat`).
3. Откроется окно с хакерской загрузкой, а затем браузер на `http://127.0.0.1:8000`.
4. Нажмите **«📷 Подключить камеру ноутбука»** в левой панели, чтобы сразу увидеть видео с вашей веб-камеры.
